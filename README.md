# plugin-dashboard

Fleet plugin monitoring dashboard for the SuperInstance agent fleet.

## Overview

Real-time dashboard for monitoring plugin health, status, and performance across the fleet.

## Installation

```bash
# Clone the repository
git clone https://github.com/SuperInstance/plugin-dashboard.git
cd plugin-dashboard

# Install dependencies
npm install

# Run the dashboard
npm start
```

## Part of the SuperInstance Fleet

This repository is part of the SuperInstance fleet — a constellation of autonomous agents, vessels, and infrastructure maintained by the Cocapn platform.
